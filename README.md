# Вариант 24. Набор системных утилит

**СТАРТОВЫЙ ПРОЕКТ ДЛЯ СТУДЕНТА**

**Покрываемые темы:** Весь курс: legacy, процессы, async, sync, parallel, GC, Registry, DLL, hooks

## Условия зачёта

Выполнить 7 обязательных заданий. Дополнительные задания повышают оценку. Код должен собираться на .NET 9.
Не допускаются пустые `catch`, блокирующие ожидания в UI-потоке и небезопасное совместное изменение состояния.

## Обязательные задания
1. Разделить приложение на сервисы и найти/исправить дефект стартового legacy-кода.
2. Запустить внешнюю утилиту через Process и прочитать результат.
3. Выполнить асинхронную файловую операцию.
4. Реализовать безопасный общий счётчик при параллельных задачах.
5. Обработать коллекцию параллельно и сравнить результат с LINQ.
6. Создать IDisposable-обёртку над FileStream.
7. Сохранить пользовательскую настройку в HKCU.

## Дополнительные задания
8. Вынести сервис в Class Library и подключить через ProjectReference.
9. Получить PID через P/Invoke.
10. Добавить ограниченный Channel pipeline.
11. Добавить WinForms KeyDown или демонстрацию безопасного hook.
12. Добавить тесты и документировать платформенные ограничения.

## Требования к сдаче

- Сохранить комментарии `TODO` и заменить их реализацией.
- Добавить отдельные классы для моделей и сервисов.
- Приложить 3–5 тестовых сценариев или пошаговую инструкцию проверки.
- Подготовить устное объяснение архитектуры и одного исправленного дефекта.
